# 4 更改配置

## 4.1 增加 mergeVirtualHostAttributes 配置

在 `manifest.json` 的 `mp-weixin` 节点下开启：

```json
"mp-weixin": {
    "appid": "wx7a804c75d979be99",
    "mergeVirtualHostAttributes": true
}
```

**作用**：允许父组件在使用自定义组件时设置的 `class`、`style` 等属性，与子组件内部根节点的属性**合并**，实现样式透传。开启后可以直接给自定义组件添加样式：

```vue
<!-- 外部 class/style 会合并到组件内部根节点 -->
<my-card class="mt20" style="position: relative;" />
```

# 6 安装 uView Plus

## 6.1 下载安装

### 方式一：VSCode 方法

通过 npm 安装（推荐）：

```bash
npm install uview-plus
```

安装后，`uview-plus` 位于 `node_modules/` 下，由 `package.json` 统一管理版本，无需手动维护 `src/uni_modules/` 目录。

### 方式二 HBuilderX 方法

HBuilderX 打开项目 → 插件市场搜索 `uView Plus` → 点击下载安装，自动放入 `uni_modules/`。

## 6.2 使用方法

**配置 easycom 规则**（`pages.json`）：

VSCode 方法（npm 安装，路径指向 `node_modules`）：

```json
"easycom": {
    "autoscan": true,
    "custom": {
        "^u--(.*)": "uview-plus/components/u-$1/u-$1.vue",
        "^up-(.*)": "uview-plus/components/u-$1/u-$1.vue",
        "^u-([^-].*)": "uview-plus/components/u-$1/u-$1.vue"
    }
}
```

HBuilderX 方法（插件市场安装，路径指向 `uni_modules`）：

```json
"easycom": {
    "autoscan": true,
    "custom": {
        "^u--(.*)": "@/uni_modules/uview-plus/components/u-$1/u-$1.vue",
        "^up-(.*)": "@/uni_modules/uview-plus/components/u-$1/u-$1.vue",
        "^u-([^-].*)": "@/uni_modules/uview-plus/components/u-$1/u-$1.vue"
    }
}
```

> 两种方法的 easycom 规则格式相同，区别仅在于组件路径：npm 版本从 `node_modules` 解析（`uview-plus/...`），插件市场版本从 `uni_modules` 解析（`@/uni_modules/uview-plus/...`）。

**引入组件样式**（`App.vue`）：

VSCode 方法（npm 安装）：

```vue
<style lang="scss">
    @import "uview-plus/index.scss";
</style>
```

HBuilderX 方法（插件市场安装）：

```vue
<style lang="scss">
    @import "@/uni_modules/uview-plus/index.scss";
</style>
```

**引入 SCSS 变量**（`uni.scss`）：

VSCode 方法（npm 安装）：

```scss
@import 'uview-plus/theme.scss';
```

HBuilderX 方法（插件市场安装）：

```scss
@import '@/uni_modules/uview-plus/theme.scss';
```

**引入全局配置**（`main.js`）：

```js
import uviewPlus from 'uview-plus'

import { createSSRApp } from 'vue'
export function createApp() {
    const app = createSSRApp(App)
    app.use(uviewPlus)
    return { app }
}
```

> 样式需 **两处引入**，分工不同：`App.vue` 中的 `index.scss` 提供组件实际 CSS 样式；`uni.scss` 中的 `theme.scss` 提供 SCSS 变量供页面引用。

配置完成后即可直接在模板中使用组件：

```vue
<template>
    <u-button type="primary">按钮</u-button>
    <u-input placeholder="请输入" />
</template>
```

# 8 http请求

封装 `uni.request` 为 Promise 风格的请求工具，统一处理**请求地址（环境变量）**、**token（请求拦截器）** 与**错误码（响应拦截器）**，页面中无需重复编写。

## 8.1 文件结构

```text
src/pages/utils/http/
├── index.ts         # 请求核心：拼接 baseURL、Promise 化 uni.request
├── types.ts         # 类型定义：RequestConfig
└── interceptors.ts  # 拦截器：请求前加 token / 响应后统一校验
```

## 8.2 请求地址环境变量配置

开发环境与生产环境使用不同后端地址，通过 Vite 环境变量区分。

根目录新建 `.env.development`（开发环境，`npm run dev:*` 时加载）：

```text
VITE_BASE_URL=http://localhost:3000
```

`.env.production`（生产环境，`npm run build:*` 时加载）：

```text
VITE_BASE_URL=https://api.example.com
```

> Vite 约定：只有以 `VITE_` 开头的变量才会暴露给客户端代码，通过 `import.meta.env.VITE_XXX` 读取。

修改环境变量后需**重启** `npm run dev:*` 才会生效。

## 8.3 类型定义（types.ts）

```ts
export interface RequestConfig {
  url: string;
  method: "GET" | "POST";
  data?: any;
  headers?: Record<string, string>;
  //   responseType?: "json" | "text";
  //   timeout?: number;
}
```

`src/env.d.ts` 中声明 `VITE_BASE_URL` 类型，避免 TS 报错：

```ts
/// <reference types="vite/client" />

interface ImportMetaEnv {
  /** 后端请求基础地址 */
  readonly VITE_BASE_URL: string;
}

interface ImportMeta {
  readonly env: ImportMetaEnv;
}
```

## 8.4 拦截器（interceptors.ts）

```ts
import { RequestConfig } from "./types";

const getToken = () => uni.getStorageSync("token") || "";

// 请求拦截器：统一附加 token
export const requestInterceptor = (config: RequestConfig) => {
  const token = getToken();
  if (token) {
    config.headers = {
      ...config.headers,
      Authorization: `Bearer ${token}`,
    };
  }
  return config;
};

// 响应拦截器：统一校验状态码与业务码
export const responseInterceptor = (response: any) => {
  if (response.statusCode !== 200) {
    throw new Error("请求失败");
  }
  if (!response.data.success) {
    throw new Error("请求失败");
  }
  return response.data.data;
};
```

- **requestInterceptor**：发起请求前执行，登录后 `uni.setStorageSync("token", ...)` 存储 token，这里自动拼到 `Authorization` 请求头
- **responseInterceptor**：拿到响应后统一判断，非 200 或业务失败直接抛错；成功则只返回 `data.data`，页面拿到的就是"干净的"数据

## 8.5 请求核心（index.ts）

```ts
import { RequestConfig } from "./types";
import { requestInterceptor, responseInterceptor } from "./interceptors";

const request = (config: RequestConfig) => {
  const processedConfig = requestInterceptor(config);
  const url = `${import.meta.env.VITE_BASE_URL}${processedConfig.url}`;
  return new Promise((resolve, reject) => {
    uni.request({
      url,
      method: processedConfig.method,
      data: processedConfig.data,
      header: processedConfig.headers,
      success: (res) => {
        try {
          resolve(responseInterceptor(res));
        } catch (error) {
          reject(error);
        }
      },
      fail: (err) => {
        reject("请求失败", err);
      },
    });
  });
};

export const get = (url: string, data?: any) =>
  request({ url, method: "GET", data });

export const post = (url: string, data?: any) =>
  request({ url, method: "POST", data });
```

要点：

- **baseURL 拼接**：`import.meta.env.VITE_BASE_URL` + 传入的相对路径（如 `/api/home/banner`）
- **Promise 化**：`uni.request` 的回调风格转为 Promise，配合 `async/await` 使用
- **拦截器接线**：请求前走 `requestInterceptor` 加 token，成功后走 `responseInterceptor` 校验并返回数据

## 8.6 使用方法

```ts
import { get, post } from "@/pages/utils/http";

// GET 请求
get("/api/home/banner", { city: "南京" }).then((res) => {
  console.log(res);
});

// POST 请求
post("/api/user/login", { phone: "138****0000", code: "1234" }).then((res) => {
  console.log(res);
});
```

## 8.7 注意事项

| 场景 | 处理方式 |
| ---- | ---- |
| 切换开发/生产环境 | 修改 `.env.development` / `.env.production`，重启 dev 生效 |
| 小程序真机预览 | `localhost` 在手机上指向手机本身，需改为电脑局域网 IP |
| H5 端跨域 | 直接请求后端接口会跨域，可在 `vite.config.ts` 配置 `server.proxy` |
| token 存储 | 登录成功后 `uni.setStorageSync("token", token)`，拦截器自动携带 |

## 8.8 涉及的关键知识点

| 知识点 | 说明 |
| ------ | ---- |
| `import.meta.env` | Vite 注入的环境变量对象，编译时按环境替换 |
| `VITE_` 前缀 | 只有该前缀开头的变量才会暴露给客户端代码 |
| `Record<K, V>` | 类型工具，`headers?: Record<string, string>` 表示键值都为 string 的对象 |
| Promise 化 | 回调风格转 Promise，支持 `async/await` |
| 拦截器 | 请求前统一加 token，响应后统一校验错误码 |

## 9.3 胶囊按钮兼容

微信小程序右上角胶囊按钮高度和位置因设备而异，通过 `uni.getMenuButtonBoundingClientRect()` 获取胶囊信息，使自定义导航栏与胶囊对齐：

```ts
import { onLoad } from '@dcloudio/uni-app'
import { ref, computed } from 'vue'

const menuButtonInfo = ref<any>(null)

onLoad(() => {
  // #ifdef MP-WEIXIN
  menuButtonInfo.value = uni.getMenuButtonBoundingClientRect()
  // #endif
  // #ifdef WEB || APP-PLUS
  menuButtonInfo.value = {
    top: '0',
    height: '44px'
  }
  // #endif
})

// 导航栏区域整体高度 = 胶囊顶部位置 + 胶囊高度 + 底部间距
const headerStyle = computed(() => {
  let style = { height: '200px' }
  // #ifdef MP-WEIXIN
  if (menuButtonInfo.value) {
    style = {
      height: `${menuButtonInfo.value.top + menuButtonInfo.value.height + 20}px`
    }
  }
  // #endif
  // #ifdef WEB || APP-PLUS
  style = { height: '90px' }
  // #endif
  return style
})

// 导航栏内容区域定位（与胶囊按钮同行）
const navStyle = computed(() => {
  let style = { top: '0', height: '44px' }
  // #ifdef MP-WEIXIN
  if (menuButtonInfo.value) {
    style = {
      top: `${menuButtonInfo.value.top}px`,
      height: `${menuButtonInfo.value.height}px`
    }
  }
  // #endif
  // #ifdef WEB || APP-PLUS
  style = { top: '20px', height: '50px' }
  // #endif
  return style
})
```

## 9.4 城市定位

点击导航栏左侧的定位图标区域，触发 `uni.getLocation()` 获取当前经纬度，再调用高德**逆地理编码**接口反查城市名，显示在导航栏上（如"南京市"）。

### 9.4.1 页面结构

导航栏左侧为可点击的定位区域，点击后触发定位：

```vue
<view class="location" @click="startLocation">
  <uni-icons type="location" color="#fff" size="28" />
  <text class="city">{{ cityName }}</text>
</view>
```

`cityName` 为响应式变量，默认空字符串，定位成功后显示城市名。

### 9.4.2 定位逻辑

```ts
const cityName = ref<string>('')

const startLocation = () => {
  uni.getLocation({
    type: 'wgs84',
    success: (res) => {
      reverseCode(res.latitude, res.longitude).then((res) => {
        cityName.value = res            // 显示城市名
      }).catch(() => {
        cityName.value = '无法定位'
      })
    },
    fail: (err) => {
      cityName.value = '无法获取位置'
      // ...分平台权限引导，见 9.4.4
    }
  })
}
```

流程：`uni.getLocation()` 拿到经纬度 → `reverseCode()` 高德逆地理编码 → 城市名回填到 `cityName`。

### 9.4.3 逆地理编码工具（utils/geoCode.ts）

封装高德 Web 服务 API（`/v3/geocode/regeo`），把经纬度转为城市名：

```ts
export const reverseCode = (latitude: number, longitude: number): Promise<string> => {
  return new Promise((resolve, reject) => {
    // 参数校验：非数字直接 reject
    uni.request({
      url: 'https://restapi.amap.com/v3/geocode/regeo',
      data: {
        key: '高德Web服务Key',           // 需在高德开放平台申请
        location: `${longitude},${latitude}`, // 注意顺序：经度,纬度
      },
      success(res) {
        const data = res.data
        if (data.status !== '1') return reject('定位失败')
        const { city, province } = data.regeocode.addressComponent
        resolve(city.length ? city : province)  // 直辖市 city 为空，用 province 兜底
      },
      fail(err) {
        reject(err)
      },
    })
  })
}
```

要点：

- **参数顺序**：`location` 必须是 `经度,纬度`，反了会导致定位失败
- **直辖市兜底**：北京、上海等直辖市 `addressComponent.city` 为空，需用 `province` 替代
- **Key 类型**：需使用高德 **Web 服务** 类型的 key（不同于 JS API key）

### 9.4.4 定位失败与权限引导（分平台）

定位失败时弹出提示框，用户确认后按平台跳转开启定位权限：

| 平台 | 处理方式 |
| ---- | ---- |
| 微信小程序 | `uni.openSetting()` 打开小程序设置页，用户手动开启定位权限 |
| App | 提示前往**系统设置**开启定位权限 |
| H5 | 提示前往**浏览器设置**开启定位权限 |

## 9.5 banner图

首页顶部轮播图，数据通过 http 请求工具从后端 `/home/banner` 接口获取。

### 9.5.1 页面结构

使用 `swiper` 轮播组件，遍历 `bannerList` 渲染图片：

```text
<view class="content">
  <swiper class="banner-swiper" indicator-dots autoplay circular indicator-color="rgba(255,255,255,0.3)" indicator-active-color="#fff">
    <swiper-item v-for="item in bannerList" :key="item.title">
      <view class="banner-item-content">
        <image :src="item.url" mode="aspectFill"></image>
      </view>
    </swiper-item>
  </swiper>
</view>
```

swiper 属性说明：

| 属性 | 作用 |
| ---- | ---- |
| `indicator-dots` | 显示底部指示点 |
| `autoplay` | 自动轮播 |
| `circular` | 循环播放（首尾衔接） |
| `indicator-color` | 指示点默认颜色 |
| `indicator-active-color` | 当前页指示点颜色 |
| `mode="aspectFill"` | 图片按比例缩放并裁切填满容器，不变形 |

### 9.5.2 类型定义（index.ts）

`src/pages/index/index.ts` 中定义轮播图数据项类型：

```ts
interface ImageItem {
  url: string;
  title: string;
}
```

### 9.5.3 请求逻辑

```ts
import { ImageItem } from './index.ts';
import { get } from '../utils/http';

const bannerList = ref<ImageItem[]>([])
const getBannerList = async () => {
  const data = await get("/home/banner");
  bannerList.value = data.banner;
}

onLoad(() => {
  // 获取banner轮播图
  getBannerList();
})
```

流程：`onLoad` 时调用 `getBannerList()` → http 工具拼接 `VITE_BASE_URL` 请求 `/home/banner` → 响应拦截器校验后返回 `data.data` → 取出 `banner` 数组赋值给 `bannerList` → 模板 `v-for` 渲染轮播项。

注意：`data.banner` 中的 `data` 是响应拦截器返回的"业务数据"（即后端响应 `data` 字段），结构为 `{ banner: ImageItem[] }`。

### 9.5.4 样式

```scss
.banner-swiper {
  width: 100%;
  height: 350rpx; // 轮播高度

  .banner-item-content {
```

## 9.6 part功能列表开发

banner 下方的功能入口列表，横向滚动展示宠物相关服务入口（如"宠物商店"、"宠物医院"等），数据通过 http 请求工具从后端 `/home/part` 接口获取。

### 9.6.1 页面结构

使用 uview-plus 的 `up-scroll-list` 横向滚动组件，遍历 `partList` 渲染图片 + 标题：

```text
<view class="part">
  <up-scroll-list indicatorColor="rgba(255,255,255,0.3)" indicatorActiveColor="#ffce2c">
    <view class="scroll-item" v-for="item in partList" :key="item.title">
      <image class="scroll-image" :src="item.url" mode="aspectFill"></image>
      <text class="item-title">{{ item.title }}</text>
    </view>
  </up-scroll-list>
</view>
```

`up-scroll-list` 是 uview-plus 组件库的横向滚动列表组件（HBuilderX 插件市场安装），常用属性：

| 属性 | 作用 |
| ---- | ---- |
| `indicatorColor` | 指示器（滚动条）默认颜色 |
| `indicatorActiveColor` | 指示器当前段颜色 |

### 9.6.2 类型定义（index.ts）

```ts
interface ImageItem {
  url: string;
  title: string;
}
```

`bannerList`（9.5.2）与 `partList` 复用同一个 `ImageItem` 类型。

### 9.6.3 请求逻辑

```ts
// 功能列表板块
const partList = ref<ImageItem[]>([])
const getPartList = async () => {
  try {
    const data = await get("/home/part");
    partList.value = data.part;
  } catch (error) {
    console.log(error);
  }
}
```

- 与 `getBannerList()` 相比多了 `try/catch`，请求失败只打日志、不阻塞页面渲染
- 后端 `/home/part` 返回结构为 `{ success: true, data: { part: ImageItem[] } }`，响应拦截器剥掉外层后取 `data.part` 赋值

## 9.7 涉及的关键知识点
